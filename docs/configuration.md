# 配置与使用

| 字段 | 填写方式 |
| --- | --- |
| Python 路径 | 独立 BabelDOC 0.6.4 环境中的 Python 可执行文件完整路径 |
| API 地址 | 服务的 OpenAI 兼容基础地址，包括服务要求的 `/v1`；必须为 HTTP/HTTPS，不接受 URL 中嵌入账号密码 |
| 模型 | 供应商实际提供且账号有权调用的模型名；插件不自动发现模型 |
| API Key | 由供应商提供；本地服务若不验密钥也需填非空占位值 |
| 记住密钥 | 可选；保存到 Zotero 密码管理器，不写入普通插件偏好 |
| 源/目标语言 | 默认 `en` / `zh`，其他语言使用 BabelDOC/模型支持的代码 |
| 页码 | 空白为全文；`1,3-5` 为第 1、3、4、5 页，页码从 1 开始 |
| 请求速率 | 1–20；应遵守供应商限流，先用较低值试运行 |
| 输出类型 | 译文、双语，或两者；默认两者 |
| 双语布局 | 左右并排或交替页 |
| 思考模式 | 默认关闭，发送 DeepSeek 风格 `thinking.type=disabled`；“开启”发送 `enabled`；“使用服务默认”不发送此参数。不支持该参数的服务应选择默认 |
| 输出 token 上限 | 默认 8192，可填 512–131072 的整数，实际须在服务允许的范围内；思考模型的预算可能同时用于推理与最终译文 |
| 忽略翻译缓存 | 默认不勾选；勾选后重新请求译文，不读取或写入翻译缓存，不删除模型和字体 |
| 保留调试记录 | 默认不勾选；保留本地诊断摘要、原文/译文和 BabelDOC 中间文件，结束后显示目录 |
| 自动 OCR | BabelDOC 的自动 OCR 功能；扫描件效果取决于原件和引擎 |

例如本地 OpenAI 兼容服务可填 `http://127.0.0.1:8000/v1`、其模型名及非空密钥。本示例地址不表示插件会安装或启动模型服务。

遇到大片空白时，先关闭思考，勾选“忽略翻译缓存”，页码填 `1,7` 等有代表性的少量页面再试。对于有正常文本层的 PDF，不必开启 OCR。需要追查时再勾选调试记录；中间文件含文档内容，不要未经检查就上传。

空响应或 `finish_reason=length` 的截断响应最多重试两次，重试遵守请求速率。持续失败、服务报错或段落译文为空时，整个文件任务会标记为失败，不导入结果；即使引擎随后回退成功，该任务也保守地拒绝导入。无效响应不会进入缓存，历史空缓存会被跳过。新版使用独立的响应保护缓存参数，避免复用旧版可能不完整的结果。此检查不能发现所有解析和排版错误，完成后仍需核对关键段落。

选择父文献时插件寻找优先原始 PDF，跳过标题以 `BabelDOC ·` 开头的生成附件。翻译多个文件时直接多选 PDF 附件；任务按顺序执行。独立附件的译文保留在同一资料库与分类中。

关闭窗口不会取消正在运行的任务，可从工具菜单重新打开。点击取消将终止当前 Python 进程并取消余下队列；已经成功导入的附件保留。重复翻译会新增附件，不覆盖之前结果。

API Key 通过 Python 标准输入传递。供应商可读取发送的文档文本，收费、模型权限及响应兼容性由该服务决定。详见 [数据与隐私](privacy.md)。
