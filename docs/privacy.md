# 数据、密钥与文件位置

## 数据流

插件在本机读取选中的 PDF，启动本地 Python/BabelDOC。BabelDOC 把需要翻译的文档文本与提示发送到你配置的模型服务；版面分析和 PDF 生成在本机执行。插件没有自建翻译服务器、账户系统或主动遥测。模型/字体等初始化资源仍需从上游下载；GitHub 更新检查会访问 GitHub。

供应商的日志、数据保留和收费政策由供应商决定。导入后的结果是普通 Zotero 附件，是否同步到 Zotero/群组库由你的 Zotero 同步设置决定。

## 密钥

默认只在内存及子进程标准输入中使用密钥，不写进命令行、普通偏好或任务 JSON 文件。勾选“记住密钥”后使用 Zotero 密码管理器；本地保护方式取决于 Zotero与系统，不能据此保证绝对安全。插件错误信息会尝试遮蔽密钥，但提交日志前仍需人工检查。

清除记住的密钥：在相同服务地址的翻译窗口中取消“记住密钥”并点击“开始翻译”；如需彻底清理，请检查 Zotero 密码管理器中该服务对应的插件登录项。取消勾选并未立即执行清除，实际清除发生在开始任务保存设置时。

## 本地文件

| 位置 | 内容 | 生命周期 |
| --- | --- | --- |
| 安装包目录 `engine/` | Python 虚拟环境及 BabelDOC 依赖 | 用户管理，不随 XPI 删除 |
| 安装包目录 `.engine-install-cache/` | Python与依赖下载缓存 | 用户管理 |
| Zotero 数据目录 `babeldoc/<插件版本>/runner.py` | 从 XPI 提取的桥接脚本 | 按插件版本存放 |
| 同目录 `job-*` | 任务中间文件与输出 PDF | 成功导入后移除；导入失败时保留 |
| 同目录 `engine-home/.cache/babeldoc/` | 模型、字体和翻译缓存等 | 持续保留，可能含原文及译文 |
| Zotero 附件存储 | 已导入的译文与双语 PDF | 按 Zotero 附件管理和同步规则 |

升级到新插件版本会使用新的桥接/缓存目录，可能重新下载资源。旧版本缓存不会自动迁移或清理。需清理时先退出 Zotero，确认没有未恢复的任务结果，再删除对应版本的缓存；下次运行需重新下载资源。
